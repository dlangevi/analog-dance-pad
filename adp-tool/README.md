# Building adp-tool

## Prerequisites

Dependencies are managed via [vcpkg](https://vcpkg.io/). You need to have `VCPKG_ROOT` set to
a vcpkg installation and pass the vcpkg toolchain file to CMake. The easiest way to do this is
via a `CMakeUserPresets.json` — see the platform sections below.

All platforms use the same configure/build commands once `VCPKG_ROOT` is set:

```
cmake --preset default    # configures and installs vcpkg dependencies (first run is slow)
ninja -C build
```

---

## NixOS / Nix

`shell.nix` provides all build dependencies and automatically generates `CMakeUserPresets.json`
with the correct Nix store path for vcpkg each time you enter the shell.

```sh
# From the adp-tool directory:
nix-shell shell.nix

# CMakeUserPresets.json is now generated. Configure and build:
cmake --preset default
ninja -C build
```

Re-enter `nix-shell` after any `nixpkgs` update to regenerate the preset with the new path.

`CMakeUserPresets.json` is gitignored — it is generated by `shell.nix` and should not be
committed.

---

## Linux (non-Nix)

Install vcpkg manually:

```sh
git clone https://github.com/microsoft/vcpkg ~/vcpkg
~/vcpkg/bootstrap-vcpkg.sh
export VCPKG_ROOT=~/vcpkg
```

Create `adp-tool/CMakeUserPresets.json`:

```json
{
  "version": 2,
  "configurePresets": [
    {
      "name": "default",
      "inherits": "vcpkg",
      "environment": {
        "VCPKG_ROOT": "/home/<you>/vcpkg"
      }
    }
  ]
}
```

Then build:

```sh
cmake --preset default
ninja -C build
```

## Windows (CMD)

```bat
git clone https://github.com/microsoft/vcpkg
vcpkg\bootstrap-vcpkg.bat
```

Create `adp-tool/CMakeUserPresets.json`:

```json
{
  "version": 2,
  "configurePresets": [
    {
      "name": "default",
      "inherits": "vcpkg",
      "environment": {
        "VCPKG_ROOT": "C:\\path\\to\\vcpkg"
      }
    }
  ]
}
```

Then build:

```bat
cmake --preset default
cmake --build build
```
